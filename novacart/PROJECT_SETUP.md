# NovaCart — Setup Instructions

## Option 1: Just open it
1. Locate the `novacart` folder.
2. Open the folder and double-click **`index.html`**.
3. It opens in your default browser — the site is ready to use.

## Option 2: VS Code Live Server (recommended for development)
1. Open the `novacart` folder in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey) from the Extensions marketplace.
3. Right-click **`index.html`** in the file explorer.
4. Select **Open with Live Server**.
5. Your browser opens automatically at `http://127.0.0.1:5500/index.html`, and the page will auto-reload whenever you save a file.

## Requirements
- Any modern web browser (Chrome, Firefox, Edge, Safari).
- No Node.js, no npm install, no build step, no backend — the project runs as static files.
- An internet connection is only used to load the Google Fonts (Space Grotesk, Inter, IBM Plex Mono). Without internet, the site still works — it just falls back to your browser's default fonts.
